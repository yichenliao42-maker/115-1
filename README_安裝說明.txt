丙級練習教室 APP V3 高級版
================================

這一版已經把前面討論的正式功能整合在一起。

【功能】
1. 蛋糕丙級 10/21（三）
2. 中餐丙級 11/4（三）
3. 自費 NT$1,500
4. 每場正式名額上限 6 人
5. 未滿時：登記狀態 = 待確認
6. 滿額時：自動進入候補
7. 管理員取消正式名額後：自動遞補第一位候補
8. 報名狀態：待確認／已確認／候補／已取消
9. 付款狀態：未付款／已付款／退款
10. 管理員後台：搜尋、篩選、編輯、取消、CSV 匯出
11. 公開 API 只回傳人數，不回傳姓名與手機
12. 管理員密碼放 Apps Script Script Properties，不寫在前端
13. 使用 LockService 防止同時搶第 6 個名額造成超收
14. 同一手機不可重複登記同一場

--------------------------------------------------
第一步：更新 Apps Script
--------------------------------------------------

1. 打開你目前那份 Google Sheet
2. 擴充功能 → Apps Script
3. 把原本 Code.gs 的內容換成這個資料夾裡的 Code.gs
4. 儲存

這是程式修改，會取代你舊版 Apps Script 程式碼。
建議先把舊程式複製一份備份再換。

--------------------------------------------------
第二步：設定管理員密碼（非常重要）
--------------------------------------------------

Apps Script 左側：
「專案設定」→「指令碼屬性」→「新增指令碼屬性」

屬性：
ADMIN_PASSWORD

值：
請設定你自己的管理員密碼，例如：
Nantou2026!abc

不要把真正密碼寫進 index.html。

--------------------------------------------------
第三步：部署
--------------------------------------------------

Apps Script 右上角：
部署 → 管理部署 → 編輯

網頁應用程式設定：
- 執行身分：我
- 誰可以存取：任何人

更新部署。

目前 APP 已預先使用你的網址：
https://script.google.com/macros/s/AKfycbxWtm1knsQuoSCE65-cKnA-_qMWWfO33dK7KS2frPtwz9oQZpiToHHpOK4RQWO3O0u10w/exec

如果你是「更新原本部署」，通常網址不會變。
如果 Google 給你新的 /exec 網址，就把 index.html 裡的 API_URL 換成新網址。

--------------------------------------------------

第五步：測試
--------------------------------------------------

建議用 Chrome 無痕模式：

https://script.google.com/macros/s/AKfycbxWtm1knsQuoSCE65-cKnA-_qMWWfO33dK7KS2frPtwz9oQZpiToHHpOK4RQWO3O0u10w/exec?action=publicStatus

2. 開 index.html

4. Sheet「報名資料」應多一列
5. 管理員後台登入後應看到該名學員
6. 測試 6 人後，第 7 人應顯示候補
7. 管理員取消其中 1 位，第一位候補會自動變成「待確認」

--------------------------------------------------
關於「已付款才算正式名額」
--------------------------------------------------

目前的規則是：
待確認 + 已確認 都會占用 6 人名額。

原因是如果「未付款完全不占名額」，同時間可能累積很多未付款登記，
實際管理會更容易超收。

如果你之後想改成：
「只有已付款才占 6 人名額」
也可以再改，但需要另外設計付款保留期限，否則容易出現大量卡位。
